# Catacombes

Un jeu d'action en vue du dessus, dans l'esprit de *The Binding of Isaac*, avec les créatures de NeoBase.

- **5 étages** de salles générées au hasard (combat, trésor, boss, et une boutique à partir du 2ᵉ étage), une mini-carte et des portes qui s'ouvrent quand la salle est nettoyée.
- **Ennemis** aux comportements variés (selon leur forme) et **boss** à plusieurs phases de tirs.
- **33 objets** (dont 3 objets actifs à débloquer) aux effets qui se cumulent, et **10 synergies** entre eux.
- **Progression** : âmes gagnées à chaque partie, héros à débloquer, sanctuaire d'améliorations, codex, succès.
- **Sauvegardes et statistiques** dans le dossier du plugin (synchronisé par NeoBase).

Commandes : les touches W A S D (ZQSD sur un clavier AZERTY, même emplacement) pour bouger, les flèches pour tirer, Espace pour l'objet actif, Échap pour la pause.

## Installer

Dans NeoBase : **NeoStore → À découvrir → Catacombes → Installer**.
